# AVIS Language — Overview

AVIS is a comment‑layer semantic language used to describe:
- module identity
- intent
- metadata
- structure
- compilation rules
- AI reasoning context

AVIS lives **inside comments**, allowing any programming language to carry
semantic meaning without altering runtime behavior.

This directory contains:
- AVIS schema files
- AVIS grammar resources
- AVIS keyword definitions
- Universe block definitions
