# MSDN SDK Reference: Cyborg/Fire-Lang
## Module: Fire-Lang V1.0

### Variable Allocation
- `begin.spec var.ansii.int.[name].val[value]` : Maps 32-bit integers to persistent registry addresses.
- `begin.spec var.ansii.string.[name].val['string']` : Locks string literals into the semantic buffer.

### Runtime Operations
- `{EXE}` : Begins logical execution of the current instruction vector.
- `[>]` : Data flow direction (Source to Sink).
- `[@]` : Direct Memory Address Pointer for address-retention.

### File Pointers
- `robot.go.to.file[ai.avis]` : Jump instruction for modular linkage.
